Sistema de Gerenciamento de Funcionários e Treinamentos

Sistema web desenvolvido para gerenciar funcionários e seus respectivos treinamentos, permitindo cadastro, organização e controle das informações de forma dinâmica.

- Funcionalidades

Cadastro de funcionários

Edição e exclusão de registros

Cadastro de treinamentos

Associação de treinamentos aos funcionários

Listagem dinâmica de dados

Validação de campos obrigatórios

Interface responsiva

- Tecnologias Utilizadas

HTML5

CSS3

JavaScript


Eventos e validação de formulários

- Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar:

Estruturação de interfaces web

Manipulação dinâmica de dados com JavaScript

Organização de informações em sistemas administrativos

Lógica de programação aplicada a cenários reais

- Conceitos Aplicados

Criação e manipulação de objetos

Arrays e controle de dados

Eventos (addEventListener)

Atualização dinâmica da interface

Separação de responsabilidades no código

- Aprendizados

Durante o desenvolvimento foram reforçados conceitos de:

Organização de código

Responsividade

Manipulação de formulários

Estruturação de sistemas administrativos
